# Application summary

I built an independent Ramp-to-Fortnox P0 experiment with immutable posting plans, explicit receipt VAT evidence and separately recoverable voucher, upload, attachment and acknowledgment steps. A read-only verifier compares every selected local frozen plan with scoped observations and preserves missing evidence, coverage and offline replay inputs. A TypeScript/Effect service on Bun and PostgreSQL implements configured sandbox grants and conservative recovery, with public CLI fault scenarios tested against real local databases and synthetic HTTP services. Actual Ramp/Fortnox interoperability remains unproved pending authorized sandbox access, calibrated receipt evidence and provider readback probes.
